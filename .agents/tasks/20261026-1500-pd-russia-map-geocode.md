# 20261026-1500-pd-russia-map-geocode — карта, поиск адреса и «Маршрут» без иностранных запросов из браузера

## Цель
Доделка 20261026-1200-pd-russia-only: браузер посетителя не обращается ни к одному внешнему домену.
Тайлы OSM — через свой nginx с кэшем (`/tiles/{z}/{x}/{y}.png`) по политике OSM; Nominatim — только с
сервера через свой API-маршрут (1 запрос/с, кэш); «Маршрут» — Яндекс Карты. Сравнение российских
сервисов транзакционной почты — без подключения.

## План
1. Сторож `verify-external-domains`: по умолчанию разрешённых внешних хостов нет (`^$`); на карте и
   профиле кофейни — тайлы со своего домена (HTTP 200, image/png, > 0 штук); на профиле кофейни — «Найти
   на карте по адресу» → запрос к своему `/api/cafe/geocode` 200 с координатами; скриншоты карты и профиля
   на 390 px. PR — прогон по проду как есть («до», ожидаемо красный).
2. `deploy/timeweb/nginx-tiles.conf` (кэш, лимиты, User-Agent с контактом, без заголовков посетителя) +
   `location /tiles/` в `nginx-domain.conf` + `install-nginx.sh` (бэкап, nginx -t, откат) + шаг в
   `deploy.yml` до `update-app.sh`; nginx -t в `domain-https` (lint).
3. `lib/geocode/nominatim.ts` (сервер: очередь 1 запрос/с, кэш, таймаут 30 с) + `app/api/cafe/geocode`
   (только `cafe_admin`); `lib/utils/geocode.ts` зовёт свой маршрут. Сначала красные тесты.
4. Тайлы в `CafeMapClient`/`CoordinatePicker` — `/tiles/…`; подпись «© OpenStreetMap» (требование
   политики OSM, без флажка Leaflet).
5. «Маршрут» → `https://yandex.ru/maps/?rtext=~<lat>,<lng>`.
6. CLAUDE.md: список известных иностранных обращений; сравнение почты — `docs/reports/`.
