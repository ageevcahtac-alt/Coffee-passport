# 20261025-1415-home-colors — цвет фона картинки на главной и поля при автозаполнении

## Разбор (до изменений)
- Картинка: `public/images/coffee-passport-four-philosophies.png`, 1672×941, PNG RGBA (альфа везде 255),
  блок `sRGB` (intent 0), без `iCCP`/`gAMA`. `app/(site)/page.tsx` — `next/image` с `unoptimized`:
  файл отдаётся как есть, без перекодирования. Профиль цвет не сдвигает — жёлтый в самих пикселях.
- Фон страницы: `body` и `main` — `--color-parchment-200` `#f5f2eb` = (245, 242, 235) (`app/globals.css`).
- Фон картинки (файл): верхняя полоса медиана (241, 232, 219), σ≈0.7; полоса над карточкой между
  колонками 2 и 3 — та же; нижняя панель «Канонический лот» (240, 231, 217). Карточка лота — отдельный
  предмет с фактурой (σ 3–5) и золотой рамкой, это не фон. Остальные стыки колонок — тонкие золотые
  линии на тёмном фото, светлого фона там нет.
- Поля: Chrome красит `:autofill` своим фоном и цветом текста с `!important` (в headless Chromium
  `rgb(232, 240, 254)` при фоне поля `rgb(250, 248, 245)`). Своих правил на автозаполнение в проекте нет.

## План
1. `scripts/images/recolor_background.py`: маска фона (пиксели ≤8 от бумаги, связанные с краем файла,
   мостики через рамку карточки разорваны эрозией 2 px; буквы и значки — заполненные дыры), мягкий край
   8 px (smoothstep), сдвиг `p + t·(цвет сайта − локальная бумага)`, t — доля бумаги в пикселе по яркости.
   Фактура и сглаживание букв сохраняются, вне маски пиксели не меняются.
2. Оригинал → `coffee-passport-four-philosophies-orig.png`; новый файл — RGB PNG без sRGB/iCCP/gAMA.
3. `app/globals.css`: `:autofill` / `:-webkit-autofill` — отложенный переход фона и цвета текста,
   поле сохраняет собственный фон, цвет текста и рамку. Касается всех форм (вход, регистрация,
   смена/сброс пароля, учётка бариста, заявка партнёра).
4. `scripts/ops/verify-home-colors.cjs` + `.github/workflows/verify-home-colors.yml`: замер прода по
   пикселям (390 и 1280 px), автозаполнение через CDP `Autofill.trigger`, скриншоты в артефакт.

## Критерии готовности
- Вне маски фона — 0 изменённых пикселей (вывод скрипта перекраски).
- Прод после деплоя: `verify-home-colors` (push) зелёный — разница фона картинки и страницы ≤2 по каждому
  каналу во всех точках на 390 и 1280 px; заполненное браузером поле = пустое поле (пиксель и стили).
- `npm test`, `npx tsc --noEmit`, `npm run lint`, `npm run build` — зелёные; `site-health` — неудач 0.
