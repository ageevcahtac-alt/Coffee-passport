# 20261025-1700-domain-https

## Цель
Рабочий https на https://coffeepassport.ru: сертификат Let's Encrypt на апекс и www с автопродлением,
301 с http://, www и IP на https://coffeepassport.ru, адрес сайта везде — домен.

## Автор
Claude (главная сессия) — по прецеденту 20261024-deploy-actions; ревью — Codex `review`.

## Разбор (domain-inspect, run 40200361013)
- DNS: A апекса и www = 147.45.102.186 (8.8.8.8, 1.1.1.1, getent на сервере), AAAA нет, NS timeweb.
- http://coffeepassport.ru → 200 (Next.js), http://www → 308 на https://coffeepassport.ru/.
- https://coffeepassport.ru и https://www → curl (60): SAN только `IP Address:147.45.102.186`.
- nginx: 443 слушает только `server_name 147.45.102.186` (default_server, сертификат coffee-passport-ip);
  у домена только `listen 80`. В /etc/letsencrypt/live только coffee-passport-ip.
- Причина: сертификат на домен не выпущен и блока `listen 443` для домена нет — nginx отдаёт
  сертификат IP (default_server). activate-domain.sh не запускался (ждал DNS).
